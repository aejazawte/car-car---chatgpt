# Car Care Collision — Website

A responsive, single-page website based on the provided logo and hand-drawn layout. Built with plain HTML, CSS, and JavaScript; no build step is required.

## Preview locally

1. Extract the ZIP (if using the ZIP package).
2. Open `index.html` in a browser, or serve the folder with any static web server.
3. Keep `styles.css`, `script.js`, and the `assets` folder beside `index.html`.

## Included

- Responsive layout for phones, tablets, and desktop.
- Pure white, mobile-friendly visual theme with the original black-background color logo.
- Business contact details, opening hours, and Google rating/reviews link.
- Why Choose Us section with insurance, towing, and deductible support highlights.
- Five coupon cards: $20 off oil change and $40 off brake service, tune-up, battery, and shocks.
- Three main service areas: Auto Repair, Collision Repair, and Towing Services.
- Searchable and category-filtered list of all 56 auto repair services.
- Repair, collision, and towing request forms.
- Multi-file photo selection and file-name preview for collision estimates.
- Click-to-call, email, directions, WhatsApp, and Google link actions.

## Important before publishing

The forms currently prepare an email draft using the visitor's default email app. A static website cannot deliver form entries or upload photos to the shop by itself. In the collision form, selected photos must be manually attached to the email draft. For production, connect the forms to a secure backend or a trusted form service that supports file uploads, spam protection, and privacy notices. Test email and phone links, business hours, and the Google link before launch.

## Deployment

This folder can be deployed to static hosting such as GitHub Pages, Netlify, or Vercel. Upload the contents of this folder, keeping the `assets` folder structure intact.
